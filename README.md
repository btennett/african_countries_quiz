# Africa Map Quiz

A mobile-friendly quiz for learning where Africa's 54 countries are. Each game asks 12 random countries, then shows a labelled map of all 54 with the ones you found highlighted.

**Play:** https://btennett.github.io/african_countries_quiz/

## Running it

A single static page with no build step: open `index.html` in a browser, or host it on GitHub Pages.

## Editing the quiz

Questions, capitals and facts live in the `quiz-data` block near the top of `index.html`.
